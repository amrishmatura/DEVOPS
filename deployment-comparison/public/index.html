3.3 Jenkins Pipeline Implementation

The Declarative Jenkinsfile defined in the repository with three stages: Install Dependencies, Deploy Application, and Verify Deployment.

pipeline { agent any stages { stage('Install Dependencies') { environment { PATH = "/opt/homebrew/bin:${env.PATH}" } steps { dir('deployment-comparison') { sh ''' node -v npm -v npm install ''' } } } stage('Deploy Application') { environment { PATH = "/opt/homebrew/bin:${env.PATH}" } steps { dir('deployment-comparison') { sh ''' nohup node server.js > app.log 2>&1 & ''' } } } stage('Verify Deployment') { steps { sh ''' for i in 1 2 3 4 5; do if curl -fsS http://localhost:3000/health; then echo "Deployment successful!" exit 0 fi sleep 2 done echo "Deployment failed!" exit 1 ''' } } } }

Project Extensibility: What Else Can You Deploy?

This comparative study pattern applies across diverse tech stacks. Below is an architectural guide showing how other projects can be deployed manually vs. via Jenkins.

1. Node.js & Express REST Service (Current Implementation)

Lightweight, fast startup, ideal for microservices and API backends.

Manual Commands: 
cd deployment-comparison
npm install
node server.js
curl http://localhost:3000/health
Jenkins Pipeline Stages: 
stage('Dependencies') { sh 'npm install' }
stage('Deploy') { sh 'nohup node server.js &' }
stage('Verify') { sh 'curl http://localhost:3000/health' }

2. React.js / Vue.js Single Page Application (SPA)

Compiles static bundles (HTML/CSS/JS) and deploys them to an Nginx web server or cloud storage bucket (AWS S3 / Vercel).

Manual Commands: 
npm install
npm run build
scp -r ./dist/* deploy@server:/var/www/html/
sudo systemctl reload nginx
Jenkins Pipeline Stages: 
stage('Build') { sh 'npm run build' }
stage('Deploy') { sh 'rsync -avz ./dist/ /var/www/html/' }
stage('Verify') { sh 'curl -I http://localhost' }

3. Python Flask / FastAPI Microservice

Common for AI/ML inference, data processing, and Python backend services.

Manual Commands: 
source venv/bin/activate
pip install -r requirements.txt
pytest
gunicorn --daemon -b 0.0.0.0:5000 app:app
Jenkins Pipeline Stages: 
stage('Test') { sh 'pytest tests/' }
stage('Deploy') { sh 'gunicorn -D app:app' }
stage('Health') { sh 'curl http://localhost:5000/health' }

4. Dockerized Full-Stack Application

Encapsulates runtime, dependencies, and OS layers in an immutable container image.

Manual Commands: 
docker build -t myapp:latest .
docker stop myapp-running || true
docker run -d -p 3000:3000 --name myapp-running myapp:latest
Jenkins Pipeline Stages: 
stage('Build Image') { sh 'docker build -t myapp:${BUILD_NUMBER} .' }
stage('Deploy Container') { sh 'docker-compose up -d --build' }
stage('Verify') { sh 'curl -f http://localhost:3000/health' }
