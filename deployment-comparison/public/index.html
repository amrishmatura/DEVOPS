3.3 Jenkins Pipeline Implementation

Declarative Jenkinsfile stored at the root of the repository. Jenkins reads this file from GitHub and executes the three stages: Install Dependencies, Deploy Application, and Verify Deployment.

Jenkinsfile — Declarative Pipeline (3 Stages)

pipeline { agent any stages { stage('Install Dependencies') { steps { dir('deployment-comparison') { script { if (isUnix()) { sh 'node -v && npm -v && npm install' } else { bat 'node -v && npm -v && npm install' } } } } } stage('Deploy Application') { steps { dir('deployment-comparison') { script { if (isUnix()) { sh 'nohup node server.js > app.log 2>&1 &' } else { bat 'start /B node server.js > app.log 2>&1' } } } } } stage('Verify Deployment') { steps { script { if (isUnix()) { sh ''' for i in 1 2 3 4 5; do if curl -fsS http://localhost:3000/health; then echo "Deployment successful!" exit 0 fi sleep 2 done exit 1 ''' } else { bat ''' powershell -Command "for ($i=1; $i -le 5; $i++) { try { $r = Invoke-RestMethod http://localhost:3000/health; if ($r.status -like '*running*') { Write-Host 'Deployment successful!'; exit 0 } } catch {}; Start-Sleep 2 }; exit 1" ''' } } } } } post { success { echo "Build Finished: SUCCESS (Ref duration: 8.4 seconds)" } } }

Project Extensibility — What Else Can You Deploy?

This comparative study pattern applies across diverse technology stacks. Below is an architectural guide showing how other projects can be deployed manually vs. via Jenkins.

1. Node.js & Express REST Service (Current Implementation)

Manual Commands

cd deployment-comparison npm install node server.js curl http://localhost:3000/health

Jenkins Pipeline Stages

stage('Install') { sh 'npm install' } stage('Deploy') { sh 'nohup node server.js &' } stage('Verify') { sh 'curl http://localhost:3000/health' }

2. React.js / Vue.js Single Page Application (SPA)

Manual Commands

npm install npm run build scp -r ./dist/* server:/var/www/html/ sudo systemctl reload nginx

Jenkins Pipeline Stages

stage('Build') { sh 'npm run build' } stage('Deploy') { sh 'rsync -avz ./dist/ /var/www/html/' } stage('Verify') { sh 'curl -I http://localhost' }

3. Python Flask / FastAPI Microservice

Manual Commands

source venv/bin/activate pip install -r requirements.txt pytest gunicorn --daemon -b 0.0.0.0:5000 app:app

Jenkins Pipeline Stages

stage('Test') { sh 'pytest tests/' } stage('Deploy') { sh 'gunicorn -D app:app' } stage('Health') { sh 'curl http://localhost:5000/health' }

4. Dockerized Full-Stack Application

Manual Commands

docker build -t myapp:latest . docker stop myapp-running || true docker run -d -p 3000:3000 \ --name myapp-running myapp:latest

Jenkins Pipeline Stages

stage('Build Image') { sh 'docker build -t myapp:${BUILD_NUMBER} .' } stage('Deploy') { sh 'docker-compose up -d --build' } stage('Verify') { sh 'curl -f http://localhost:3000/health' }
